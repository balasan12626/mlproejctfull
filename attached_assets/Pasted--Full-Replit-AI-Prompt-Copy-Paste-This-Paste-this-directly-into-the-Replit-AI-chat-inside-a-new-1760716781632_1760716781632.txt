🧩 Prompt for Replit AI
You are my coding assistant. I want to create a complete full-stack application inside Replit that uses:

- Backend: FastAPI (Python)
- Frontend: React.js (Vite)
- Both must run inside the same Replit project
- When I press the “Run” button, Replit should automatically:
  1. Install dependencies
  2. Build the React app
  3. Start the FastAPI backend
  4. Serve the React build through FastAPI
- Everything should run from one public Replit URL.

👉 Requirements:
1. Create the **full folder structure** and all necessary files.
2. Include working code for each part.
3. Configure `.replit` and `replit.nix` so that “Run” builds frontend and launches backend automatically.

👉 Functional requirements:
- FastAPI must have an endpoint `/api/hello` that returns:
  `{ "message": "Hello from FastAPI backend!" }`
- The React frontend should call this endpoint and display the returned message on the screen.
- Serve the built React app (`frontend/dist`) using `StaticFiles` in FastAPI.

👉 Generate these files with complete content:
- main.py (FastAPI backend serving React build)
- requirements.txt (FastAPI dependencies)
- frontend/package.json (React/Vite app config)
- frontend/vite.config.js
- frontend/src/App.jsx (React frontend code)
- run.sh (build frontend + start FastAPI)
- .replit (Replit run configuration)
- replit.nix (Replit environment configuration)

🧠 Goal:
After I paste these files into Replit, clicking “Run” should:
1. Build the React app automatically
2. Start FastAPI
3. Serve React + API from a single URL like `https://myapp.replit.app`

📘 What Each File Does
🧠 1️⃣ main.py

FastAPI backend file — runs the server and serves React build folder.

/api/hello → API endpoint

/ → serves React app (frontend/dist)

CORS enabled for communication between React & FastAPI.

🧩 2️⃣ requirements.txt

Python dependencies list.

fastapi
uvicorn


Later you can add:

google-generativeai
crewai


for AI integrations.

⚛️ 3️⃣ frontend/

React.js app created with Vite.
Contains all frontend logic and UI.

⚙️ 4️⃣ frontend/package.json

Tells Node which dependencies and scripts to use.

Scripts:

npm run build → builds React app

npm run dev → runs React in development mode

🧭 5️⃣ frontend/vite.config.js

Configures the React build output folder to dist.

🧱 6️⃣ frontend/src/App.jsx

Main React file that:

Fetches data from /api/hello

Displays the backend message in UI.

🧩 7️⃣ run.sh

Automates everything when you press “Run” in Replit.

Installs Node modules

Builds the React frontend

Starts FastAPI server

⚙️ 8️⃣ .replit

Tells Replit which command to execute when “Run” is pressed.
It runs the run.sh script automatically.

⚙️ 9️⃣ replit.nix

Defines Replit’s environment dependencies:

Python 3.11

FastAPI + Uvicorn

Node.js 20

npm

This makes both Python and Node.js available in the same Replit container.
